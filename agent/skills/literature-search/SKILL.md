# 文献与资料检索

## 工作顺序

1. 先在实验室内知识库用 `lab_knowledge_search` 查找已有笔记、流程与经验，避免重复检索。
2. 知识库没有可用内容时，用 `lab_web_search` 做联网检索；检索词包含物种、基因/蛋白名与主题关键词。
3. 需要精确文献时，在检索词中加入 `review`、`protocol`、`Arabidopsis` 等限定词，或用年份限定最新进展。
4. 汇总时逐条给出标题、链接与摘要要点，并注明来源站点。
5. 只有用户明确要求保存时，才调用 `lab_knowledge_save`，默认保存为私有。

## 结果质量要求

- 优先学术来源（期刊、大学、数据库官网、协议平台），营销页面不作为主要依据。
- 区分“已验证”和“未验证”：只转述检索结果中出现的信息，不补造作者、年份、DOI 或影响因子。
- 同一条结论尽量给出两个独立来源；来源冲突时并列说明。
- 检索结果为空或接口失败时，明确告知用户，并建议调整关键词后重试。
