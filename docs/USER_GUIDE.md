# D509 工作台使用说明（面向实验室成员）

本页讲「每天怎么用」。部署与运维见 [DEPLOY.md](DEPLOY.md)、[ARCHITECTURE.md](ARCHITECTURE.md)。

## 1. 登录与入口

- 内网入口：`http://192.0.2.10/`
- Tailscale 入口：`http://198.51.100.71/`
- 从哪个入口进入，页面内所有服务链接都会自动使用同一个主机，不用手动换 IP。
- 统一身份由 Casdoor 提供。第一次登录若提示修改初始密码，按页面要求完成后才能使用其它功能。

> 新账号初始密码由管理员在账号管理里生成并一次性展示；不要使用旧清单里的口令。

## 2. 第一次进来：先看哪里

首页快捷入口只放高频动作：**AI 助手、文件空间、课题资料、组会汇报、种子管理、文献检索、LaTeX、命令速查、PDF 工具箱、内网/邮箱相关入口**。左侧导航分三组：

| 分组 | 主要页面 |
| --- | --- |
| 工作 | 首页、个人工作台、Agent 助手、知识库、文件存储、种子管理、组员共享、课题资料、组会汇报 |
| 科研 | 文献检索、生信实训、引物设计、PDF 工具箱、公共数据库等 |
| 系统（管理员/教师） | 账号与权限、服务状态、后台任务、备份归档 |

快捷键：`Ctrl/⌘ + K` 打开命令面板，直接输入页面名或服务名跳转；命令面板里的「新手引导」可随时重看互动引导。

## 3. 文件与资料

### 个人文件 `/files`

- 支持上传文件、上传文件夹、新建文件夹、**新建文件**（手机上可直接起草文本）。
- 每种文件按类型显示图标，列表/网格/时间线等视图可切换。
- 删除进回收站，保留 7 天；文件审计与回收站口径一致。
- 文本类文件可在线编辑，采用 ETag 乐观并发：若别人已改，会返回 409，必须刷新后再改，避免覆盖。
- PDF 文件的「更多」里可一键进入 **PDF 工具箱**，不需要先下载再上传。

### 课题组资料

- `/research`（课题资料）：按 `{进组日期}-{姓名}` 分目录，学生只看自己那棵，老师看全部。**仅 lab-teacher 用户组可见，管理员不自动穿透。**
- `/meetings`（组会汇报）：按 ISO 周 `YYYY-Www` 归档，每个周目录单独授权；未授权目录完全不可见。新建一周时可点「沿用上周授权」把上周名单复制过来（只加不减）。
- `/shared`（组员共享）：`共享文件-组员/{学号}_{姓名}/{01_组会汇报,02_论文,03_其他}`。学生只查看+上传（不能下载/建子目录，48 小时内可删）；导师全权。
- 组会材料与组员共享目录的分工：按周提交到组会归档走 `/meetings`；自己的长期材料放 `/shared` 里对应子目录，两页有互相跳转入口。

## 4. PDF 工具箱 `/pdf`

用门户自绘的 Ant Design 页面调用本机 Stirling PDF，**文件不出内网**：

- 整理：合并、按页拆分、按份数/大小拆、按书签拆、海报拼版、自动拆页
- 编辑：旋转、重排、删页、压缩、修复
- 安全：加密码、去密码、净化（去脚本与元数据）

结果直接下载；操作有并发/超时/上传体积上限。

## 5. AI 助手、知识与文献

- `/agent`：AgentScope 2.0.11 驱动，工具覆盖门户业务（文献/种子/组会/课题资料）、知识库语义检索、工作台捕获与绘图。回答带 `source`/`chunk_index` 引用来源。
- `/knowledge`：知识库管理与问答。建库时平台自动配置 `bge-m3 / 1024` 嵌入占位；检索可返回来源文件。
- `/literature`：PubMed / Europe PMC / Crossref / UniProt / NCBI Gene 统一检索。结果可「存入知识库」，也可「AI 解读」直接交给 Agent。
- 种子台账 `/seeds` 可按标签精确筛选，并可「让 Agent 分析」当前筛选结果（不会修改台账）。
- 所有「交给 Agent」都通过一次性信箱：只在当前标签页生效，读后即焚，刷新不会重复注入。

## 6. 种子管理与多维表格

- `/seeds`：种子入库、存放、备份台账；支持扫码录入（本地 OCR）、Excel 导入导出、卡片/时间线/突变类型看板；字段含突变类型、突变基因、标签。
- `/lab?tab=tables`（多维表格空间）：用 Baserow API 自绘的表格页面，不是 iframe。删除后 6 秒内可「撤销」；支持跨页全选范围提示、键盘操作（↑↓ 选行 / Enter 编辑 / Esc / Ctrl+Z）。

## 7. 邮件 `/mail`

- 后端是 Mailbox 服务（只收不发），凭据加密存储在服务自己的数据库。
- 门户前端用同源 `/mail/` 代理接入，页面由门户自绘；具体账号由管理员配置。
- 目前只启用 `imap / pop3 / jmap` 收信协议，不能从平台发信。

## 8. 安全与网络

- 防火墙两档：`normal`（默认）：LAN 只放行对外入口端口，文件核心/后端/备份等内部服务只走 Tailscale；`strict`：LAN 只留 DNS，全部流量强制走 Tailscale。
- 切换命令：`ops/lab-firewall-mode.sh normal|strict|confirm|status`。切换后 90 秒内要 `confirm`，否则自动回滚。
- 如果局域网设备打不开 `192.0.2.10`，先确认防火墙档位是不是被切到了 `strict`。
- 备份、审计、回收站保留期与页面提示一致；敏感密钥不进备份卷。

## 9. 遇到问题

1. 先点顶栏帮助中心的「互动引导」重看流程。
2. `Ctrl/⌘ + K` 搜索页面名；很多"找不到入口"其实是入口在子菜单里。
3. 管理员看 `/admin/status` 的服务状态与 `/admin/tasks` 的定时任务日志。
4. 数据丢失类问题先看回收站（7 天）与多维表格删除提示里的「撤销」。
